# 《模拟真实广告公司全流程》AIGC实训闯关 · 单手泡泡龙

本项目专为《模拟真实广告公司全流程》课程打造，深度融合 **6大广告公司核心工位（AI教练带教）**、**12项核心专业知识点** 与 **6大课程思政真实项目案例**，采用适合手机/平板/电脑单手连贯操作的泡泡龙互动实训形式。

## ✨ 核心亮点

1. **深度结合《模拟真实广告公司全流程》课程体系**：
   - **课时1 · 创意方法（AIGC创意教练）**：任务一「挖掘项目创意并完成AI初阶生图」｜知识点：广告创意 BRIEF 解读、AI 生成基础逻辑｜思政与案例：乡村振兴与社会责任 ·《美丽南方研学》AI 生图案例
   - **课时2 · 提示词工程（AIGC提示词教练）**：任务二「提示词优化技巧与系列精制作」｜知识点：提示词四维编写逻辑、系列海报视觉统一性原则｜思政与案例：科技伦理与责任 ·《果园场景提示词精准优化习题》
   - **课时3 · 合规审查（合规审查员）**：任务三「AI辅助广告合规审查」｜知识点：《广告法》等规范知情形、商用素材版权规范｜思政与案例：版权意识与法治观念 · 涉农广告《广告法》典型违规案例集
   - **课时4 · 排版设计（排版设计师）**：任务四「画面构修与版式排版设计」｜知识点：平面排版原则、品牌视觉统一规范｜思政与案例：工匠精神与审美素养 · 学生代表示范AI排版工具应用
   - **课时5 · 方案制作（路演陪练员）**：任务五「设计说明撰写与路演方案制作」｜知识点：设计说明结构化表达、提案 PPT 逻辑框架｜思政与案例：创新精神与家国情怀 · 智能体：路演陪练员·商业广告专项版
   - **课时6 · 路演答辩（答辩评委）**：任务六「项目提案答辩与优化迭代」｜知识点：商业提案现场展示要求、临场答辩技巧｜思政与案例：团队协作与沟通能力 · 八桂田园项目优秀作品终评选代案例
2. **发射区单手连贯操控**：
   - **拇指原位切弹**：点击炮台两侧的 `A / B / C / D` 换弹槽、在发射台左右滑动，或点击底部拇指操控舱均可实时切换上膛炮弹并同步预览选项内容。
   - **按住瞄准松手即射**：在画布按住拖动可激活激光瞄准线，松手即刻射出；答对后自动延时连闯下一题，全程无弹窗打断。
3. **数字化三栏课程全景图谱 & 老师自定义加题**：
   - 内置 1:1 数字化还原的三栏交互式课程图谱（广告公司全流程｜核心知识点｜思政育人与案例），点击任意课时即可切入对应实训关卡。

## 🚀 GitHub Pages 一键部署步骤

1. 登录 GitHub，点击右上角 **`+`** -> **`New repository`** 创建一个公开仓库（如 `aigc-bubble-quiz`）。
2. 解压本压缩包，将里面的全部文件（`index.html`、`aigc_bubble_quiz.html`、`assets/`、`README.md`、`.nojekyll`）上传至仓库根目录并点击 **`Commit changes`**。
3. 进入仓库顶部的 **`Settings`** -> 左侧菜单 **`Pages`**。
4. 在 **`Build and deployment`** -> **`Branch`** 下选择 **`main`** 分支（目录选 `/ (root)`），点击 **`Save`**。
5. 等待约 1 分钟后刷新页面，即可获取你的专属在线实训网址：`https://<你的GitHub用户名>.github.io/<仓库名>/`。

## 📱 课堂分发方式

- **在线（推荐日常）**：直接把网址或二维码发给学生。二维码见 `assets/qr_paopaolong.png`，课堂内也可点击“课程图谱”页右上角 **课堂码** 按钮投屏。
- **离线（无网教室）**：把 `offline/paopaolong_offline.zip` 发给学生，解压后双击 `paopaolong_offline.html` 即可进入，无需联网，样式、字体、二维码全部内置。
- **局域网**：教师电脑在本目录执行 `python -m http.server 8000`，学生连接同一 WiFi 后访问 `http://教师电脑IP:8000`。
- 成绩排行榜保存在各学生自己的浏览器中，不跨设备汇总；如需全班榜单，需要额外的在线提交接口。
